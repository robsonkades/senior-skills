# Original evaluation inputs

These files preserve the Portuguese inputs used in the six historical runs. They are evidence,
not current skill instructions. They were copied without changing their bytes before translating
the maintained documentation and cases into English.

- [Discovery case](cases/discovery.txt)
- [Solution and readiness case](cases/solution-readiness.txt)
- [Context case](cases/context.txt)
- [Frozen evaluation rubric](rubric.txt)

The case hashes in [snapshots.json](../snapshots.json) refer to these files. Raw answers remain in
`../results/`, and the original self-reported read logs remain in [runs.json](../runs.json).
The translated cases in `../cases/` have not been executed. Historical runs must not be presented
as validation of the later English package revisions.
